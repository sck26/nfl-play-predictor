How it works

Simple, explainable rules.

  • Long yardage favors passes.
  • Short yardage favors runs.
  • Third and fourth down affect the decision.
  • No live NFL data or trained model is used in this version.
This prototype does not claim a measured accuracy. A reported 80% result from another model should only be included after its dataset and evaluation can be verified.
Architecture

Small serverless footprint

S3 static website → HTML/CSS/JavaScript UI → AWS Lambda function URL (optional) → Python JSON response.

The page has a browser fallback so it works before AWS deployment.
